# 네트워크 모듈

기존 마라톤 프로젝트의 VPC를 재사용하지 않고 이길로 전용 VPC를 생성합니다.

- 가용 영역마다 공개, 앱 전용, DB 전용 서브넷을 각각 생성합니다.
- 공개 서브넷은 ALB와 NAT용이며 인스턴스 공개 IP 자동 할당은 끕니다.
- 앱 서브넷은 NAT를 통해 HTTPS로 ECR·로그·비밀값 서비스 등에 접근합니다. 같은 리전 S3는 gateway endpoint로 연결합니다.
- DB 서브넷은 인터넷·NAT 기본 경로 없이 VPC 내부에서만 통신합니다.
- 수신은 인터넷 → ALB 80/443 → 앱 8080 → PostgreSQL 5432로 제한합니다. 관리 포트 8081과 SSH는 열지 않습니다.
- ALB·ECS·RDS 자체는 다음 단계에서 이 모듈의 ID 출력값을 사용해 생성합니다.

기본 CIDR은 환경에서 전달합니다. /16 입력 시 공개는 세 번째 옥텟 0부터, 앱은 16부터, DB는 32부터 /24로 배정합니다. AZ 목록 순서를 바꾸면 서브넷 CIDR이 바뀌므로 기존 배포에서는 순서를 유지합니다.

`single` NAT는 첫 번째 AZ의 게이트웨이를 공유합니다. 해당 AZ 장애 시 다른 AZ의 앱도 외부 통신에 영향을 받을 수 있습니다. AZ별 외부 통신이 필요하면 `per_az`로 설정합니다. 두 방식 모두 실제 AWS 적용 시 NAT 사용 요금이 발생합니다.
