# 서버 이미지 저장소

환경별 ECR 저장소를 생성합니다. 태그 덮어쓰기를 금지하고 push 시 취약점 검사를 요청합니다. 이미지는 SSE-S3와 별개인 ECR의 AES256 저장 암호화를 사용합니다.

태그는 서버 Git 커밋 SHA를 사용하고 동일 태그를 다시 올리지 않습니다. ECS 배포 단계에서는 가능한 한 이미지 digest를 사용합니다. `latest`에 의존하지 않습니다.

태그 없는 이미지만 14일 후 자동 삭제합니다. 태그가 붙은 이미지는 롤백을 위해 보관하며, 별도 보존 정책은 배포 운영 단계에서 정합니다. 이미지가 남아 있는 저장소는 강제로 삭제하지 않습니다.
